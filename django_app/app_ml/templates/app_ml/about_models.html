CNN Image Classifier

Conv2D MaxPooling Adam Accuracy: ~78%

Modelo de clasificación de imágenes entrenado para distinguir entre tres clases: Dog, Cat, Bird. Utiliza capas convolucionales para extraer características visuales (bordes, texturas).

Architecture Specs
  • ├─ Input: Imágenes RGB normalizadas (150x150).
  • ├─ Layers: 3 bloques de Conv2D + MaxPooling para reducción dimensional.
  • ├─ Flatten: Capa densa de 128 neuronas con activación ReLU.
  • └─ Output: Softmax (3 neuronas) para probabilidad multiclase.

LSTM Sentiment Analysis

Embedding LSTM Dropout 0.3 Accuracy: ~82%

Red neuronal recurrente (RNN) tipo LSTM diseñada para procesar secuencias de texto. Analiza reseñas de videojuegos para predecir sentimiento binario (Recomendado/No Recomendado).

Training Specs
  • ├─ Embedding: Vectorización de palabras (Dim 128).
  • ├─ Core: LSTM Layer (128 units) con recurrent_dropout para evitar overfitting.
  • ├─ Loss: BinaryCrossentropy.
  • └─ Output: Sigmoide (0 a 1) para clasificación binaria.
